# Диплом - часть 3.
# Автоматизированное UI тестирование веб-приложения Stellar Burgers с использованием паттерна Page Object 

## Использованные библиотеки:

- pytest - фреймворк для написания и запуска тестов
- Selenium WebDriver - инструмент для автоматизации действий браузера
- requests - библиотека для выполнения HTTP-запросов к API
- allure - инструмент для создания наглядных отчетов о тестировании

### Структура проекта

- `pages` - классы страниц с описанием методов взаимодействия с элементами (Page Object)
- `locators` - пакет с локаторами элементов страниц
- `tests` - пакет, содержащий тесты
- `conftest.py` - фикстуры для тестов
- `helpers.py` - вспомогательные функции
- `data.py` - тестовые данные
- `urls.py` - URL-адреса API и страниц приложения

### Запуск автотестов

**Установка зависимостей**

> `$ pip freeze > requirements.txt`

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание allure-отчета**

>  `$ python -m pytest tests/ -v -k chrome --alluredir=allure_results`

**Просмотр allure-отчета в браузере**

>  `$ allure serve allure_results`

## Реализованные тесты

### Восстановление пароля (test_recovery_password_page.py)
- Проверка перехода на страницу восстановления пароля
- Проверка ввода email для восстановления
- Проверка видимости пароля при клике на значок "показать/скрыть"

### Личный кабинет (test_account_page.py)
- Проверка перехода в личный кабинет
- Проверка перехода в раздел "История заказов"
- Проверка выхода из аккаунта

### Основной функционал (test_main_page.py)
- Проверка перехода в раздел "Конструктор"
- Проверка перехода в раздел "Лента заказов"
- Проверка открытия и закрытия модального окна с информацией об ингредиенте
- Проверка увеличения счетчика при добавлении ингредиента
- Проверка оформления заказа авторизованным пользователем

### Лента заказов (test_order_feed_page.py)
- Проверка открытия модального окна с деталями заказа
- Проверка отображения заказов пользователя на странице "Лента заказов"
- Проверка увеличения счетчиков "Выполнено за все время" и "Выполнено за сегодня"
- Проверка появления номера заказа в разделе "В работе"
